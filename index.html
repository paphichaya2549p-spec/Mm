📝 1. คะแนนดิบ (Raw Score)

ความหมาย: คะแนนที่ได้จากการทดสอบโดยตรง ก่อนนำไปแปลงรูป

📌

ข้อจำกัด

หน่วยวัดไม่สมบูรณ์ และความหมายไม่ชัดเจนในตัวเอง

⚠️

เปรียบเทียบไม่ได้ตรง ๆ

คะแนนเต็มและความยากของข้อสอบแต่ละวิชาอาจต่างกัน

ตัวอย่าง: ได้ 35 คะแนนจากข้อสอบ 50 คะแนน ยังไม่บอกโดยลำพังว่าผู้เรียนอยู่ในตำแหน่งใดเมื่อเทียบกับกลุ่ม

🔄 2. คะแนนแปลงรูป (Derived Score)

นำคะแนนดิบมาแปลงให้อยู่ในรูปที่ตีความหรือเปรียบเทียบได้เหมาะสมขึ้น

📐 คะแนนมาตรฐาน Z (Z-score)

บอกว่าคะแนนของบุคคลอยู่สูงหรือต่ำกว่าค่าเฉลี่ยกี่หน่วยส่วนเบี่ยงเบนมาตรฐาน (SD)

Z = (X − X̄) / SD

X = คะแนนดิบ | X̄ = ค่าเฉลี่ย | SD = ส่วนเบี่ยงเบนมาตรฐาน

⬆️

Z เป็นบวก

สูงกว่าค่าเฉลี่ย

➖

Z = 0

เท่ากับค่าเฉลี่ย

⬇️

Z เป็นลบ

ต่ำกว่าค่าเฉลี่ย

✏️ ตัวอย่าง: X = 80, X̄ = 70, SD = 5 → Z = (80 − 70) / 5 = 2
แปลว่า คะแนนสูงกว่าค่าเฉลี่ย 2 SD

🌟 คะแนนมาตรฐาน T (T-score)

แปลงจาก Z-score ให้อ่านง่ายขึ้น ลดปัญหาค่าติดลบ โดยมีค่าเฉลี่ย 50 และ SD เท่ากับ 10

T = 10Z + 50

ค่าเฉลี่ย = 50 | ส่วนเบี่ยงเบนมาตรฐาน = 10

✏️ ตัวอย่าง: ถ้า Z = 2 → T = 10(2) + 50 = 70

🧠 สูตรจำหน้าแรก

Raw Score = คะแนนที่ได้โดยตรง

Z-score = บอกตำแหน่งเทียบค่าเฉลี่ยเป็นหน่วย SD

T-score = 10Z + 50 → ค่าเฉลี่ย 50, SD = 10

🔔 3. คะแนน T-ปกติ (Normalized T-score)

ความหมาย: การแปลงคะแนนโดยอาศัยตำแหน่งของคะแนนในกลุ่ม แล้วเทียบตำแหน่งนั้นกับการแจกแจงแบบโค้งปกติ

เหมาะในกรณีที่ต้องการให้คะแนนแปลงมีความหมายตามตำแหน่งบนโค้งปกติ แม้คะแนนดิบเดิมจะไม่ได้แจกแจงเป็นโค้งปกติ

🎯 จุดสำคัญ: ต้องพิจารณาลำดับคะแนน ความถี่สะสม ตำแหน่งเปอร์เซ็นต์ไทล์ และตารางโค้งปกติ ไม่ใช่นำคะแนนดิบไปแทนในสูตร T = 10Z + 50 โดยตรงทุกกรณี

📈 เปอร์เซ็นต์ไทล์ (Percentile Rank: PR)

บอกตำแหน่งสัมพัทธ์ของคะแนนเมื่อเทียบกับสมาชิกในกลุ่ม โดยคำนึงถึงความถี่ของคะแนน

PR = [(cf + ½f) / N] × 100

cf = ความถี่สะสมก่อนถึงคะแนนนั้น

f = ความถี่ของคะแนนนั้น | N = จำนวนผู้เข้าสอบทั้งหมด

⚠️ ใช้สูตรตามนิยามที่รายวิชากำหนด เพราะบางตำราอาจนิยามการคำนวณ PR แตกต่างกันเล็กน้อย

🧩 เปรียบเทียบคะแนนแปลงรูป

ประเภท จุดประสงค์ / ลักษณะ
Z-score บอกระยะห่างจากค่าเฉลี่ยเป็นหน่วย SD ค่าเฉลี่ย 0 และ SD 1
T-score แปลงจาก Z เพื่อให้อ่านง่าย ค่าเฉลี่ย 50 และ SD 10
Normalized T-score อาศัยตำแหน่งเปอร์เซ็นต์ไทล์และตารางโค้งปกติเพื่อแปลงคะแนน

💭 จุดที่มักสับสนในข้อสอบ

  • Z-score เป็นลบ ไม่ได้แปลว่าคะแนนดิบติดลบ แต่หมายถึงต่ำกว่าค่าเฉลี่ย
  • T-score ทั่วไป คำนวณจาก Z ด้วยสูตร T = 10Z + 50
  • Normalized T-score อาศัยอันดับ/PR และโค้งปกติ จึงไม่ควรสับสนกับ T-score ทั่วไป
  • PR 80 หมายถึงตำแหน่งเปอร์เซ็นต์ไทล์ที่ 80 ไม่ได้แปลว่าได้คะแนนดิบ 80 คะแนน

⭐ จำลำดับนี้ให้แม่น

เรียงคะแนน → cf และ f → PR → ตารางโค้งปกติ → Normalized T

👥 2. การตัดเกรดแบบอิงกลุ่ม

Norm-Referenced Grading

ตัดสินผลโดยเปรียบเทียบคะแนนของผู้เรียนกับผู้เรียนคนอื่นในกลุ่มเดียวกัน เพื่อพิจารณาตำแหน่งสัมพัทธ์

วิธีกำหนดช่วงเกรด

วิธีที่ 1: ใช้พิสัย (Range)

R = คะแนนสูงสุด − คะแนนต่ำสุด

ความกว้างของช่วงเกรด = R ÷ จำนวนช่วงเกรด

วิธีที่ 2: ใช้ค่าเฉลี่ยและ SD

ใช้ค่าเฉลี่ยเป็นจุดอ้างอิง และใช้ SD ช่วยกำหนดช่วงคะแนน

วิธีที่ 3: ใช้โค้งปกติ

ใช้ค่าเฉลี่ยและ SD ประกอบการจัดกลุ่มตามตำแหน่งบนโค้งปกติ

✅

ข้อดี

เห็นตำแหน่งของผู้เรียนในกลุ่มอย่างเป็นระบบ

⚠️

ข้อจำกัด

เกรดขึ้นกับความสามารถของกลุ่ม และอาจต่างกันแม้คะแนนใกล้เคียงกัน

🎯 3. การตัดเกรดแบบอิงเกณฑ์

Criterion-Referenced Grading

เปรียบเทียบผลการเรียนกับเกณฑ์หรือจุดประสงค์ที่กำหนดไว้ ไม่ได้ตัดสินจากอันดับของเพื่อนในกลุ่ม

ตัวอย่าง: A ≥ 80%

ผู้เรียนได้ระดับ A เมื่อมีผลตามเกณฑ์ที่กำหนดตั้งแต่ 80% ขึ้นไป

ข้อดี

ช่วยให้เห็นเป้าหมายชัดเจน ส่งเสริมแรงจูงใจและความร่วมมือ และสอดคล้องกับมาตรฐานวิชาชีพ

ข้อจำกัด

เกณฑ์ของผู้สอนอาจต่างกัน และต้องตรวจสอบความเหมาะสมและความเชื่อถือได้ของเกณฑ์

🤝 4. การตัดเกรดแบบผสม

ใช้แนวคิด อิงกลุ่ม + อิงเกณฑ์ ร่วมกัน โดยพิจารณาความเหมาะสมของรายวิชา จุดประสงค์ และนโยบายการประเมิน

🧠 จำเปรียบเทียบให้ขึ้นใจ

อิงกลุ่ม = เทียบเพื่อน | อิงเกณฑ์ = เทียบเป้าหมาย | แบบผสม = ใช้ทั้งสองแนวทาง
